# WordPress-модули Presentonika

Здесь лежат собственные WordPress-модули Presentonika:

- `plugins/core` — основная логика сервиса;
- `plugins/ui` — личный кабинет и пользовательский интерфейс;
- `plugins/vk-id-auth` — вход и подключение аккаунта VK.

Ядро WordPress, загрузки пользователей, архивы презентаций, логи, дампы базы и серверные настройки сюда не добавляются.

## Проверка

Перед упаковкой модулей выполните:

```bash
composer test
```

Секреты задаются только на сервере и не должны попадать в Git.
